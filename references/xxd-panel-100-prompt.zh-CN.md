# XXD Panel 100｜运行适配器（中文）

本文件不是第二套美学提示词。生成时必须先完整读取 `references/original-prompt/zh-CN.md`；它是 100 的唯一创作与审美权威。若首行 Markdown 标题只是内部归档标签，则不进入生图请求；除此之外的原始提示词正文逐字使用。当前归档若没有该标题，则全文逐字进入生图请求。本文件只负责把用户本次选择的运行变量追加到正文末尾。

执行、问询、尺寸、多模式、壁纸、出图与输出目录规则以 `references/soldier-runtime.md` 为准。`SKILL.md` 只提供本编号身份与覆盖条款。

## 不可改写的边界

- 不总结、翻译、扩写或“优化”原始提示词。
- 不额外规划颜色、色板、材料、构图、留白、标题、微文案或美学动机。
- 原始提示词中的颜色处理逻辑保持原样：它要求从照片取色就取色，它规定固定色系就使用固定色系。
- 原始提示词中的文字逻辑由图像模型执行；外层 Skill 不提前写标题或文案包。
- 用户选择的模式和尺寸完整替换旧的 3:4 上下容器，不覆盖其余审美规则。对照模式始终严格 50:50。
- 每张成品只追加一个已选模式的指令，不把其他模式作为备选项一同发送。
- 每张普通成品都从本次原始图片一次直达生成；禁止把中间风格图、旧结果、样张或其他 Panel 成品作为第二轮参考。唯一例外是用户明确选择的连贯壁纸套装。

## 四选一模式块

每张成品只追加下面一个模式块。

```text
输出模式：TOP_BOTTOM
生成一张完整画布，严格只有两个横贯全宽的水平区域：REALITY VIEW 精确占上方 50%，TRANSFORMED DESIGN 精确占下方 50%，只在画布垂直中点分界。不得增加顶部、底部或中间条带，不得出现独立标题栏、拼贴或第三分区。所有文字必须位于下方 50% 内。原稿要求的内部网格、边框、容器与侧栏留在下方 50%。只可决定各区内部裁切或环境延展、留白与排版，不得改变 50:50。
```

```text
输出模式：LEFT_RIGHT
生成一张完整画布，严格只有两个贯穿全高的垂直区域：REALITY VIEW 精确占左侧 50%，TRANSFORMED DESIGN 精确占右侧 50%，只在画布水平中点分界。不得旋转成上下构图。不得增加顶部、底部或中间条带，不得出现独立标题栏、拼贴或第三分区。所有文字必须位于右侧 50% 内。把原文上下方位词映射为左右，保留全部审美与严格等分。原稿要求的内部网格、边框、容器与侧栏留在右侧 50%。只可决定各区内部裁切或环境延展、留白与排版，不得改变 50:50。
```

```text
输出模式：DESIGN_ONLY
整张画面完全使用 TRANSFORMED DESIGN 的设计转译语言。REALITY VIEW 只作为不可见的主体身份、结构关系、颜色逻辑与事实依据；每个可见元素都属于原始提示词规定的设计转译结果，而不是未经转译的原始照片展示。
```

```text
输出模式：WALLPAPER_PACK
设备：<本张已确定的 PHONE、IPAD、DESKTOP 或 WATCH>
壁纸关系：<已确定的 INDEPENDENT 或 LINKED>
为当前设备创作一张完整画布的 TRANSFORMED DESIGN 壁纸。REALITY VIEW 只作不可见参考；根据设备画布与可用屏幕空间重新构图，每个可见元素都属于设计成品。
```

在所选模式块后只追加一种文字模式。若用户还有其他明确要求，将其逐字放在文字模式块之后，也就是全部内容最末尾。

### 模型根据原始提示词生成文字

```text

TEXT LANGUAGE: <用户确认的语言或地区>

由图像模型按照原始提示词已有的文字生成逻辑生成。所有可见文字都应从
当前图片的内容、气质或隐喻中自然生长。任何以事实或资料形式呈现的信息，
必须来自用户提供、图片清晰可见或已经核实的真实信息；没有事实依据时，
使用诗意而非事实性的表达。运行层本身不是画面文案的来源。
保留原文的字体层级、尺度、材料与位置；原稿要求的大标题不得被降成小 caption。
```
