# XXD Panel 100｜运行适配器（中文）

本文件不是第二套美学提示词。生成时必须先完整读取 `references/original-prompt/zh-CN.md`；它是 100 的唯一创作与审美权威。当前归档没有 Markdown 标题，因此原始提示词全文逐字进入生图请求；若未来归档增加纯管理用途的标题，只省略该标题。本文件只负责把用户本次选择的运行变量追加到正文末尾。

## 不可改写的边界

- 不总结、翻译、扩写或“优化”原始提示词。
- 不额外规划颜色、色板、材料、构图、留白、标题、微文案或美学动机。
- 原始提示词中的颜色处理逻辑保持原样：它要求从照片取色就取色，它规定固定色系就使用固定色系。
- 原始提示词中的文字逻辑由图像模型执行；外层 Skill 不提前写标题或文案包。
- 用户选择的模式和尺寸完整替换旧的 3:4 上下容器，不覆盖其余审美规则。
- 每张成品只追加一个已选模式的指令，不把其他模式作为备选项一同发送。

## 四选一模式块

每张成品只追加下面一个模式块。

```text
输出模式：TOP_BOTTOM
整张画面的主结构只有上下两个主要部分：REALITY VIEW 在上，TRANSFORMED DESIGN 在下，共同组织完整画布。由图像模型根据原图、原始提示词和最终画布决定两部分的视觉比例、内部裁切或环境延展、留白与文字布局。
```

```text
输出模式：LEFT_RIGHT
整张画面的主结构只有左右两个主要部分：REALITY VIEW 在左，TRANSFORMED DESIGN 在右，从画布顶部到底部共同形成完整的左右构图。所有可见内容与文字都融入这套左右结构；由图像模型自主决定不对称宽度、内部裁切或环境延展与留白。
```

```text
输出模式：DESIGN_ONLY
整张画面完全使用 TRANSFORMED DESIGN 的设计转译语言。REALITY VIEW 只作为不可见的主体身份、结构关系、颜色逻辑与事实依据；每个可见元素都属于原始提示词规定的设计转译结果，而不是未经转译的原始照片展示。
```

```text
输出模式：WALLPAPER_PACK
设备：<本张已确定的 PHONE、IPAD、DESKTOP 或 WATCH>
壁纸关系：<已确定的 INDEPENDENT 或 LINKED>
为当前设备创作一张完整画布的 TRANSFORMED DESIGN 壁纸。REALITY VIEW 只作不可见参考；根据设备画布与可用屏幕空间重新构图，每个可见元素都属于设计成品。
```

在所选模式块后只追加一种文字模式。若用户还有其他明确要求，将其逐字放在文字模式块之后，也就是全部内容最末尾。

### 模型根据原始提示词生成文字

```text
TEXT MODE: ORIGINAL_PROMPT_GENERATED
TEXT LANGUAGE: <用户确认的语言或地区>

由图像模型按照原始提示词已有的文字生成逻辑生成。所有可见文字都应从
当前图片的内容、气质或隐喻中自然生长。任何以事实或资料形式呈现的信息，
必须来自用户提供、图片清晰可见或已经核实的真实信息；没有事实依据时，
使用诗意而非事实性的表达。运行层本身不是画面文案的来源。
```

### 使用用户准确文字

```text
TEXT MODE: USER_EXACT
TEXT LANGUAGE: <用户确认的语言或地区>
TEXT: 「<用户准确文字>」

逐字使用，不改写、不翻译、不纠错、不添加其他文案。
排版方式与字体气质继续服从原始提示词。
```

### 不要文字

```text
TEXT MODE: NONE
画面中不得出现任何字母、文字、数字、标题、标签、Logo 或伪文字。
```
