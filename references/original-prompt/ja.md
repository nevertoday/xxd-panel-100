# XXD Panel 100｜原文プロンプト（日本語閲覧訳）

アップロード写真を一枚ずつ独立した上質なデザインポスターにし、複数写真を結合しません。3:4縦構図、上下領域は高さを厳密に1:1、各50%とします。

上部は元写真の主体、構造、姿勢、実在する質感、自然光、元の色彩の空気を保ち、アート雑誌・独立出版・展覧会画像の質感になる軽い調整だけを行います。必要なら環境を自然に拡張しますが、主体を伸縮・歪曲・変更しません。

下部は最も識別しやすい主体、輪郭、姿勢、物語関係を抽出し、Naïve folk-inspired narrative illustration／稚拙な民藝感を持つ質感豊かな平面物語絵へ再構成します。写真全体を描き写さず、細部を削り、シルエット、原始的な形、少数の色面、図符で語り直します。

簡略シルエットと大きな primitive forms、flattened perspective、クレヨンやオイルパステル、粗い鉛筆の粒子、紙の透けと手仕事の不完全さを用います。色は写真から鮮やかで記憶に残るものを少数選び、暖白い紙と暗いシルエットを基底にします。明るく清潔で、濁りや蛍光色を避けます。

物語の中心、視覚的重心、正負形、大小のリズム、余白を重視します。主体は偏置・部分裁切も可能で、遠くから構造が明快、近くで手作業の粒子と素朴なユーモアが見えるようにします。

文字は少量だけ。固定タイトル、場所、番号、言語を設けず、主体や感情から意味ある語を導きます。手刷りのずれと不規則な字間を持つ民藝的編集書体や少量の手書きを、看板・メニュー・メモのように自然に絵へ統合します。児童カートゥーン、写実、滑らかなベクター、複雑な遠近、3D、EC向け挿絵、テンプレート効果を避けます。
