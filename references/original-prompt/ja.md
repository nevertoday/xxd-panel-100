# XXD Panel 100｜原文プロンプト（日本語閲覧訳）

アップロードした各写真を、それぞれ独立した上質なデザインポスターにしてください。複数画像を結合せず、写真ごとに個別出力します。全体は3:4の縦構図とし、上下二つの領域の高さを厳密に1:1、各50%にします。

上半分には元写真を残し、主体の同一性、構造、姿勢、実在する質感、自然な光と影、元の色彩の空気を保ちます。調整は軽い上質なカラーグレーディングだけにとどめ、アート雑誌、独立出版物、展覧会写真のような質感にします。画幅に合わせて周囲の環境を自然に拡張しても構いませんが、主体を引き伸ばしたり、歪めたり、変更したりしてはいけません。

下半分では、写真の中で最も識別しやすい**主体、輪郭、姿勢、物語上の関係**を抽出し、**Naïve folk-inspired narrative illustration／稚拙な民藝感を持つ質感豊かな平面物語挿絵**として再構成します。写真全体を描き写さず、細部を積極的に省き、シルエット、原始的な形、少数の色面、図符化した要素によって元画面を語り直します。主体の同一性と物語関係を保つために最も有効な視覚的手掛かりだけを残し、元の対象が一目で分かりながら、朴訥さ、ユーモア、生活感を備えた表現にします。

主体の造形は**簡略化したシルエットと大きな primitive forms** を中心にします。人物、動物、建築、植物、器物、乗り物は、厳密な遠近法や解剖を求めず、比率を適度に圧縮し、構造を要約し、特徴を誇張して構いません。空間には flattened perspective を使い、高低、遮蔽、大小、色面の関係によって物語をつくります。補助物は視覚記号のようにリズミカルに配置し、複雑な背景は積極的に削除して、一つの中心的な動作、関係、場面に主要な物語を担わせます。

画面には**クレヨン、オイルパステル、粗い鉛筆、乾性画材のような粒子質感**を使います。黒または濃色の領域を均一に塗りつぶさず、拭い、摩擦、重ね塗り、途切れ、紙の透けを残します。輪郭には手仕事の誤差と少し不器用な感覚を持たせ、縁を完全に整えなくても構いません。全体は平面的に保ち、写実的な光と影、金属素材、複雑な立体感、滑らかなデジタルベクターは使いません。

上の写真から**最も鮮やかで、記憶に残り、主体の精神を最もよく表す色**を選んで再構成し、簡潔で明るい limited color palette をつくります。色の清潔さと生命力を高め、暖白の紙面と濃色のシルエットを安定した基底にします。そのうえで、元写真から青、赤、黄、緑、ピンク、オレンジなど少数の spot-color accents を自然に抽出し、衣服、植物、食べ物、建築の一部、物語の焦点に使います。色は明瞭でも過度に飽和させず、大きな明暗対比と小さな差し色でリズムをつくります。灰色に濁った色、暗く沈んだ色、モランディ化、蛍光色、安価なキャンディ感は避けます。

構図では**物語の中心、視覚的重心、正負形、大小のリズム、余白の関係**を重視します。主体は中央に置く必要はなく、片側へ寄せ、部分的に裁ち落とし、補助要素とゆるい三角関係をつくっても構いません。粗いシルエットと小さな色要素が呼吸できる十分な空白を残します。遠くからは構造が明快に見え、近くでは手仕事の粒子と少し天真な造形の面白さが見えるようにし、すべての要素を均等に敷き詰めてはいけません。

文字は少量だけ介入させ、固定の題名、場所、番号、言語をあらかじめ設定しません。写真の主体、動作、生活状態、感情、文化的文脈から、意味のある少量の文字を自由に抽出します。**軽やかで素朴な、手刷りのわずかな見当ずれと不規則な字間を持つ民藝的編集書体**を使い、少量の手書き文字を組み合わせても構いません。文字は看板、メニュー、メモ、出版物の注記のように画面へ自然に存在させます。主体、机、壁、余白、場面の構造に沿ってずらしながら配置し、図形とともに物語へ参加させますが、整然とした商業タイトル欄にはしません。

全体は、**稚拙なシルエット、平面的な空間、クレヨンの粒子、限定色、民藝記号、編集的な物語性**が一体となった視覚表現にします。親しみがあり、ユーモラスで、素朴で、知的で、生活感を持ちながら、成熟した構図とデザイン意識を保ちます。子ども向けカートゥーン、かわいいステッカー、写実的な挿絵、滑らかなベクター、複雑な遠近法、精密な顔立ち、過剰な細部、3Dレンダリング、EC向け挿絵感、テンプレート化した効果は避けます。
